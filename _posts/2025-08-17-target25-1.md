**How I found the flag**
1. Open Opensearch 
2. Change the Index Pattern to "SMTP" because I want to view email servers and other related information.
*What is SMTP?* 
>Email client uses SMTP to connect to your email provider's mail server and send the message. The server then uses SMTP to forward the email to the recipient's mail server, which ultimately delivers the email to the recipient's inbox.
3. Set the date range to what I want to view.
4. Search for “security@personalyz.io”, which is the security team's email address.
![Opensearch1](/assets/img/target2025_d2_1.png)
5. There are many emails, over 300, but I remember that the subject the threat actor used for the email we have. The subject contains "data".
![Opensearch2](/assets/img/target2025_d2_2.png)
6. Search for "data" using the search function (Ctrl+F).
7. Found an email! I double-check that the email path matches. Yes, it uses 250.24.46.164.
If I couldn't find the email by searching for "data," I could also use 250.24.46.164 to search for related emails.
