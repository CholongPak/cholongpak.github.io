## Challenge

**Introduction**

At this point, you're pretty sure someone made a malicious commit to the Git repo, causing the data exfiltration. The goal of this step is to figure out how the attacker got the credentials of the Git committer.  

To start, note down the username of the Git committer from "Shadow Commit." That person's password will be the flag for this assignment.  

**Objectives**

As part of your forensics, you've been given access to Personalyze.io's backup server, which has a full copy of all the data from their company server.

First, find out how to log into the backup server: [target-securevault.chals.io](https://target-securevault.chals.io/)  
Once you're logged in, you can download all the files from Personalyze. It's about 50 MB.  
Next, search through the files for the leaked credentials. They're in there! And you'll find out how the attacker could have obtained them...  

**Flag format**

The flag for this challenge is the password for the credentials that you found. (Only the password - no username.)
It starts with "wicys".  

**Required tools**

You'll need a web browser, and a way to open .tar.gz files. (On Windows, you'll need an archive extractor like WinRAR or 7Zip. On Mac, it is available on the command line, or through various free apps.)  
You'll need a good text editor like VSCode to view some of the files.  
There is one part of the challenge that requires a working Python installation; however you can also skip it and still find the answer fairly easily.  

**Additional resources**

None for this challenge.  
There are no hints for this challenge.  


## How I found the flag

1. First, I needed to find the password to log in to the website. The username provided was admin.
![login webpage](/assets/img/target2025/target2025_d10_1.png)
2. I reviewed the HTML of the login page and found  
"admin: atob("V2lDeXNfU2VjdXJlVmF1bHRfQ2hhbGxlbmdlXzIwMjUh")"  
"backupoperator: atob("QmFja3VwT3BzMTIz")"  
"readonly: atob("Vmlld09ubHkyMDI1")"  
![found password in HTML](/assets/img/target2025/target2025_d10_2.png)
3. Using CyberChef and decoded the value using BASE64.  
"V2lDeXNfU2VjdXJlVmF1bHRfQ2hhbGxlbmdlXzIwMjUh" = "WiCys_SecureVault_Challenge_2025!"  
"QmFja3VwT3BzMTIz" = "BackupOps123"  
"Vmlld09ubHkyMDI1" = "ViewOnly2025"  
4. So, the admin password was WiCys_SecureVault_Challenge_2025!. I used this to log in successfully.
5. Downloaded the file MAIN-SERVER-01 (size: 2.4GB).
![logged in the website](/assets/img/target2025/target2025_d10_3.png)
![downloaded the file](/assets/img/target2025/target2025_d10_4.png)
6. The downloaded file contained over 200 files. Although I had the actor's name, elesiuta, it was tough to find any hints or the flag. I searched for "elesiuta" and found two files.
![searched elesiuta](/assets/img/target2025/target2025_d10_5.png)
7. There was no password. I opened many files at random trying to check, but that was a really bad idea. The next day, I suddenly remembered that the two files I found from "elesiuta" search had some Slack messages. There was also a Slack archive file in the IT drive. I opened that file and found the encoded data:
ZXNsZXNpdXRhOndpY3lzX3NsYWNrX2ZsYWdfMjAyNSE=
![slak archive file](/assets/img/target2025/target2025_d10_6.png)
![found the flag](/assets/img/target2025/target2025_d10_7.png)
8. Decoded that string and got: eslesiuta:wicys_slack_flag_2025!

**Flag: eslesiuta:wicys_slack_flag_2025!**

## MITER ATT&CK Mapping

**Tactic**: Credential Access [TA0006](https://attack.mitre.org/tactics/TA0006/)  
The attacker successfully obtained login credentials from a compromised user account by extracting them from backup files and Slack message archives.

**Technique**: Unsecured Credentials: Credentials In Files [T1552.001](https://attack.mitre.org/techniques/T1552/001/)  
The attacker discovered base64-encoded credentials embedded in Slack archive files. The credentials were improperly stored and easily retrievable, allowing unauthorized access to sensitive credential.
