## Step 1: AWS VPC & Networking Setup

### 1.1 VPC Configuration

The foundation of this infrastructure is a custom Virtual Private Cloud (VPC) named Nextcloud-vpc. I configured it with a CIDR block of 10.0.0.0/16, providing a private address space ranging from 10.0.0.0 to 10.0.255.255. 
>_[(CIDR: Classless Inter-Domain Routing)](https://en.wikipedia.org/wiki/Classless_Inter-Domain_Routing)_ 

To ensure a highly available and resilient network environment, I implemented the following components:

- Multi-AZ Architecture: I distributed the network resources across two Availability Zones (us-east-1a and us-east-1b). This design prevents service interruptions by ensuring that if one data center encounters an issue, the system remains operational in the other zone.

- Public Subnets: Two public subnets were created to allow the EC2 instance and other resources to communicate with the internet via an Internet Gateway.

- S3 Gateway Endpoint: To optimize data transfer, I established an S3 Gateway Endpoint. This allows the VPC to communicate directly with Amazon S3 over the private AWS backbone network, significantly enhancing security and reducing latency by bypassing the public internet.

### 1.2 Security Groups (Virtual Firewalls)

Security is a top priority for this project. I implemented two distinct Security Groups to enforce the Principle of Least Privilege, ensuring that each resource only accepts the specific traffic required for its function.

- NextcloudSecurityGroup: TThis group acts as the primary firewall for the EC2 instance, controlling all inbound and outbound traffic. I opened the following ports to the public (0.0.0.0/0):  
        - SSH (22): For secure remote server management.  
        - HTTP/HTTPS (80, 443): For standard web access to the Nextcloud interface.  
        - Custom TCP (8080, 8443): Specifically required for the Nextcloud All-In-One (AIO) management dashboard.  

![nextcloud_security_group](/assets/img/aws_cloud/nextcloud_security_group.png)

- EFSSecurityGroup: This group manages access to the Elastic File System. It is configured to allow NFS (Port 2049) traffic only from the NextcloudSecurityGroup, ensuring that only the authorized application server can access the configuration files.

![efs_security_group](/assets/img/aws_cloud/efs_security_group.png)
