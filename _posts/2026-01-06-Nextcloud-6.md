After launching the master container, the rest of the setup happens on the web-based AIO interface.

### 5.1 Initial Setup

Access the Dashboard: Duck DNS https://rrcnextcloud1030.duckdns.org:8443  
Security Warning: Browser showed "Your connection is not private" warning. Advanced -> continue.  
Retrieve Setup Password: The interface displayed a unique Initial Setup Password.

Configuration Settings:
  - Backup Directory: Leave this empty for the initial setup.
  - Additional Apps: Enable Collabora Online to allow document editing while optimizing system resources.
  - Timezone: Set to America/Winnipeg (or your local timezone) for accurate logging.

![aio_configuration1](/assets/img/aws_cloud/aio_configuration1.png)

Deployment process orchestrates the launch of multiple Docker containers and typically takes 10–15 minutes.  
Once all containers turn green, note the Admin username and password displayed on the screen.

![aio_configuration2](/assets/img/aws_cloud/aio_configuration2.png)

### 5.2 Configure Backups

- In the AIO interface, set the backup directory to /mnt/efs/backup.
- Note the encryption password.
- Click "Create backup" to make an initial backup. Wait for it to complete.

![aio_backup](/assets/img/aws_cloud/aio_backup.png)

### 5.3 Mount S3 Bucket

Enable the App: Navigate to Apps > External storage support and Enable.  

![nextcloud_s3_1](/assets/img/aws_cloud/nextcloud_s3_1.png)

Mount the S3 Bucket:  
Go to Administration Settings > External storage and add a new storage of type Amazon S3:  
  - Folder name: Data  
  - Authentication: Set to None (The EC2 instance uses its assigned IAM Role to access the bucket securely without keys).  
  - Bucket name: nextcloud.rrc.ca.cholong
  -	Region: us-east-1
  - SSL: Enable SSL

Once saved, a green checkmark will appear, indicating that Nextcloud has successfully established a private link to the S3 bucket via the VPC Endpoint.

![nextcloud_s3_2](/assets/img/aws_cloud/nextcloud_s3_2.png)

### 5.4 User Management

I created a dedicated user account to test the system:

Navigate to Administration > Users > Add user to create a standard account, separating administrative tasks from daily file management.
