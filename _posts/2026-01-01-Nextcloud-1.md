**Project Overview**

The goal of this project was to deploy a secure, scalable, and user-friendly file-sharing and backup solution using Nextcloud. By hosting this on AWS, I created a private cloud environment that serves as a powerful alternative to public storage providers, offering full control over data privacy.

**Core Architecture & Workflow**

The solution is built on a AWS infrastructure.

>Networking & Security: The system operates within a custom AWS VPC with public subnets. Access is managed via Duck DNS and a static Elastic IP, with Security Groups acting as a virtual firewall to strictly control inbound traffic on essential ports (80, 443, 8080, 8443).
>
>Compute: The application is containerized using Docker and hosted on an Ubuntu-based EC2 instance. This setup ensures a consistent, isolated, and easily reproducible runtime environment.
>
>Decoupled Storage Strategy:
>- Amazon EFS: Provides persistent network storage for critical configuration and database files, ensuring data survives even if the instance is terminated.  
>- Amazon S3: Serves as the primary object storage backend for high-capacity user files, offering cost-effective and durable storage.
>
>Monitoring & Reliability: Amazon CloudWatch provides real-time health monitoring and automated alerts for system availability. Meanwhile, AWS Backup centralizes and automates recovery points for EBS, EFS, and S3 to prevent data loss.
